## 🚀 Projects

### [Aesthetic Application — Demo](https://github.com/ThomasDixini/AplicativoEsteticaDemonstracao)
A full stack system for managing aesthetic appointments. Backend in .NET 9 with JWT authentication, mobile app in React Native (Expo), push notifications via Firebase Cloud Messaging, NGINX as a load balancer, and Docker Compose with horizontal scaling support. CI/CD with GitHub Actions, unit tests with xUnit and Moq.

### [Event-Driven Notifications — RabbitMQ Demo](https://github.com/ThomasDixini/dotnet-rabbitmq-demo)
A demonstration of an event-driven architecture with .NET 10 and RabbitMQ. Direct Exchange with independent queues for clients and administrators, Dead Letter Queue for failure handling, Worker Services consuming in the background, and integration with Expo Push Notifications. Docker Compose and CI/CD configured.

### [Design Patterns](https://github.com/ThomasDixini/DesignPatterns)
Repository with practical implementations of the main Design Patterns in .NET, each pattern including a bad example vs. a good example and real-world usage context.
